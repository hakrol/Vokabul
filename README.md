# Games

Kort oversikt over spillene i `games/` og hvordan de startes lokalt.

## Spill
- Vokabularspill: Gjett betydningen av ord (20 ord per runde) og få en ovelsesliste. Start via `games/vokabularspill/index.html`.
- Synonymspill: Finn tre synonymer per oppgave (10 oppgaver per runde) med vanskelighetsgrad og bonus. Start via `games/synonymspill/index.html`.
- Ordgjettespill: Skriv inn riktig ord ut fra en beskrivelse og bygg lengste rekke. Start via `games/ordgjettespill/index.html`.
- Kontinuum: Sorter ord etter intensitet mellom to ankere. Laster React, Babel og Tailwind via CDN (krever nett). Start via `games/kontinuum/index.html`.
- Legacy Vokabularspill: Eldre variant med repetisjon og retning no-en/en-no. Ordlisten kan endres i `games/legacy-vokab/app.js` (ORD). Start via `games/legacy-vokab/index.html`.

## Start lokalt
- Åpne `index.html` i rotmappen for spillhuben, eller åpne hver `index.html` direkte.
